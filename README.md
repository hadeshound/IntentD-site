# IntentD — публичный сайт

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Zod.

## Запуск

```bash
cp .env.example .env.local
npm install
npm run dev
```

Требуется работающий портал на `http://localhost:8080` (см. `../portal`).
Без него страницы всё равно отрисуются: каталог тарифов подменяется локальной
копией сид-данных, а формы покажут ошибку сети.

## Структура

```
app/
  layout.tsx                  шрифты, AuthProvider, шапка, подвал, skip-link
  page.tsx                    лендинг, все девять секций
  (public)/pricing            тарифы + матрица возможностей
  (public)/docs/api           SDK, Ingest API, схема данных, доставка, примеры
  (public)/contact            расширенная форма + FAQ
  (public)/terms, /privacy    юридические документы
  auth/*                      вход, регистрация, восстановление, сброс пароля
  checkout                    защищённая заявка на тариф
components/ui                 кнопки, поля, модал, аккордеон, код-блок, glow
components/marketing          секции лендинга, шапка, подвал, формы
components/auth               формы аутентификации и AuthGuard
components/checkout           панель оформления заявки
lib/api                       клиент HTTP и обёртки эндпоинтов
lib/schemas                   Zod-схемы, зеркалящие серверную валидацию
lib/hooks                     useAuth, useZodForm, usePlans, useReveal
lib/content                   тексты тарифов, FAQ, навигации, документации
lib/utils                     cn, форматирование, безопасные редиректы
```

## Дизайн-система

Палитра и типографика заданы в `tailwind.config.ts`; дефолтная палитра
Tailwind не используется.

| Роль | Значение |
|---|---|
| Фон | `#0B0F17` (`void`) |
| Слои карточек | `#111827`, `#1F2937` (`carbon-800/700`) |
| Акцент | `#10B981` / `#059669` (`mint-500/600`) |
| Свечение | `#6366F1` (`violet-500`) — только ambient glow, не заливка кнопок |
| Заголовки | `#FFFFFF` (`ink`) |
| Текст | `#9CA3AF` (`ink-muted`) |
| Границы | `rgba(255,255,255,0.08)` (`hairline`) |

Шрифты: **Golos Text** (заголовки), **Manrope** (текст), **JetBrains Mono**
(код и лейблы). Причина отхода от пар в ТЗ описана комментарием в
`app/layout.tsx`: ни Syne, ни Space Grotesk, ни Plus Jakarta Sans, ни Clash
Display не содержат кириллицы, а весь контент русский.

Приёмы вёрстки: асимметричные сетки 7/5 и 6/6 со смещением по вертикали,
перекрытие слоёв, крупная типографика с `clamp()`, тонкие границы 1px,
glassmorphism на шапке и акцентных карточках, размытые цветовые пятна за
ключевыми блоками, hover как подъём на 2px плюс потепление границы.

Анимируются только `transform` и `opacity`. Появление блоков при скролле —
IntersectionObserver (`lib/hooks/useReveal.ts`), срабатывает один раз.
`prefers-reduced-motion` отключает и дрейф свечений, и пульсацию индикатора,
и появление блоков.

## Сессии

Access-токен хранится в модульной переменной внутри `lib/api/client.ts` — то
есть в памяти вкладки и нигде больше. Refresh-токен лежит в HttpOnly-cookie,
которую этот код прочитать не может. При 401 на защищённом запросе клиент один
раз молча обновляет сессию и повторяет исходный запрос; если и это не удалось,
`AuthProvider` сбрасывает состояние.

## Доступность

Семантические заголовки и списки, `aria-expanded` на аккордеоне и мобильном
меню, `aria-describedby` от поля к его ошибке, `role="alert"` на сообщениях
формы, видимое кольцо фокуса на тёмном фоне, ловушка фокуса и возврат фокуса в
модальном окне, skip-link первым в порядке табуляции, настоящие `<table>` с
`scope` в матрице тарифов и схеме данных.

```bash
npm run build
```

Все три проходят на Node.js 24.19.0 (`tsc --noEmit` без ошибок, ESLint без

## Известная проблема с зависимостями

`npm audit` помечает линейку Next.js 14 как уязвимую. Проект переведён на
14.2.35 — последнюю заплатку в мажоре, который задан в ТЗ. Полностью убрать
предупреждения нельзя без перехода на Next 16: диапазон в advisory охватывает
всё вплоть до `16.3.0-preview.10`, а это ещё и React 19 и асинхронные
`searchParams`.

Перечисленные advisory касаются функций, которых в приложении нет: Pages
Router с i18n, Server Actions, Image Optimization API, кастомный сервер,
middleware. Проверено: ни `next/image`, ни `'use server'`, ни `middleware.ts`,
ни `i18n` в конфиге не используются. Это снижает риск, но не закрывает вопрос:
решение о переходе на Next 16 за вами.
